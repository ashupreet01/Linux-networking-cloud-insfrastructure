# Linux CLI Commands

## Introduction

Linux Command Line Interface (CLI) allows users to interact with the operating system by entering commands in the terminal. It is commonly used for system administration, file management, networking and server management.

## Basic Linux CLI Commands

### 1. pwd

The pwd command shows the current working directory.

Command: pwd

Example output: /home/ashu

### 2. whoami

The whoami command shows the name of the currently logged-in user.

Command: whoami

Example output: ashu

### 3. uname -a

The uname -a command displays detailed information about the Linux system and kernel.

Command: uname -a

### 4. ls

The ls command lists files and directories in the current directory.

Command: ls

### 5. mkdir

The mkdir command is used to create a new directory.

Command: mkdir practice

### 6. cd

The cd command is used to move from one directory to another.

Command: cd practice

### 7. ip addr

The ip addr command displays network interfaces and IP addresses.

Command: ip addr

### 8. clear

The clear command clears the terminal screen.

Command: clear

### 9. sudo apt update

The sudo apt update command refreshes the package information available to the system.

Command: sudo apt update

### 10. systemctl status

The systemctl status command is used to check the status of a system service.

Command: sudo systemctl status apache2

### 11. systemctl start

The systemctl start command starts a service.

Command: sudo systemctl start apache2

### 12. curl

The curl command can be used to test a web service or make requests to a URL.

Command: curl http://localhost

It can also be used to test connectivity using an IP address.

Command: curl http://10.0.2.15
