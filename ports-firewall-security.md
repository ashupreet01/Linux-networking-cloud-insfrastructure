# Ports, Firewall and Cloud Security

## Introduction

Security is an important part of Linux and cloud infrastructure. Firewalls and security rules help control network traffic and protect systems from unauthorized access.

## Network Ports

A port is a logical communication endpoint used by applications and services.

Some common ports are:

- Port 22: SSH
- Port 80: HTTP
- Port 443: HTTPS

Different services use different ports to communicate over a network.

## Firewall

A firewall controls incoming and outgoing network traffic according to defined rules.

It can allow trusted traffic and block unwanted or unauthorized connections.

## Why Firewall is Important

A firewall helps:

- Reduce unauthorized access.
- Control network traffic.
- Protect services running on a server.
- Reduce the attack surface of a system.

## Security Groups

In cloud environments, security groups act as virtual network controls. They can be configured to allow or restrict traffic to cloud resources.

For example, a web server may allow HTTP traffic on port 80 and HTTPS traffic on port 443.

## Linux Security Practices

Important security practices include:

- Keep the operating system updated.
- Use strong passwords.
- Protect SSH private keys.
- Use secure authentication.
- Allow only required network ports.
- Avoid unnecessary services.
- Monitor system activity.
- Give users only the permissions they need.

## Apache Security

Apache is a web server that should be properly configured and protected. Only the required ports and services should be accessible.
